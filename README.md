## The line

> My grandfather, who farmed those hills all his life, told me never to curse the rain for being late, but to mend the roof while I waited.

## How it works

`main.ts` writes that single fixed sentence to `/output/entry.txt`. Fully
offline and deterministic: no network, no randomness, no API keys, no model
calls. A runtime self-check asserts the line passes the gate (1–200
characters, non-blank, single line) before writing.

## Run

```sh
node main.ts
cat /output/entry.txt
```
